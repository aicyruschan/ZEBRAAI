# Kling 3.0 Prompt：TC501 EP01 寫實版（R1–R5）

> 寫實版 Composition：`TC501-EP01-Real`（繁）、`TC501-EP01-Real-Hans`（簡）。
> 生成後存為 `assets/clips/r1.mp4` … `r5.mp4`，然後執行 `npm run prep && npm run render:real`。缺少的片段會顯示灰色占位。
> 本環境沒有 Kling 金鑰，而且網絡政策封鎖外部 API，所以要你在 Kling 介面生成。

## 生成設定（依 Kling 3.0 公開資料，**請以 Kling 官方文件為準**）
- 比例 16:9；mode 選 pro（或 4K）；每段長度見下表。Kling 3.0 單段可生成 3–15 秒（第三方指南，未經官方核實）。
- **關閉原生音效（generate_audio = false）**：聲音由專案的合成 BGM 和音效負責；片段放入後也會自動靜音。
- **連貫性**：
  - 先把工作人員建立成「主體／Element」，R1–R5 全部引用同一個 Element
  - R2 之後每段用上一段的最後一幀作 `start_image`
- **TC501 參考圖**：`assets/products/tc501/2.jpg`（正面）、`1.jpg`（背面）。AI 生成的產品外觀可能有誤（鏡頭位置、綠色側鍵、ZEBRA 字樣），每段都要逐幀檢查。設備保持在中距離，螢幕背向鏡頭，可以減少穿幫。

## 共用設定（每段末尾附上）
```
寫實企業宣傳片風格，現代化倉庫收貨區，地面有黃色安全線，背景有整齊的金屬貨架。一個黑色塑膠棧板上整齊疊放 12 個紙箱（3 列 × 4 層），每個紙箱正面貼有白色收貨標籤，標籤上只有條碼圖案，沒有可讀文字。LED 照明加自然光，色調乾淨。人物：30 歲左右亞洲工作人員，深灰色工作服，乾淨俐落。電影感淺景深，穩定器運鏡，16:9。不要人聲對白，不要背景音樂，畫面中不要出現任何可讀文字或品牌標誌。
```
**Negative prompt：** 可讀文字, 字幕, 浮水印, 品牌標誌, 變形的手, 多餘手指, 扭曲的設備, 螢幕朝向鏡頭, 雷射照射人眼, 人物看鏡頭

## R1 痛點（8 秒 → `assets/clips/r1.mp4`）
```
中景側拍。工作人員站在棧板前，手持【舊式設備】，逐一對準每個紙箱的條碼標籤掃描，每次只讀一個，紅色瞄準光一次只照一個標籤；掃完一箱就彎腰、轉身換下一箱，動作重複，略顯疲累。 + 共用設定
```

## R2 登場（8 秒 → `assets/clips/r2.mp4`）
參考元素 @TC501：`2.jpg`、`1.jpg`；`start_image` 用 R1 最後一幀
```
工作人員把【舊式設備】放到身旁推車上，拿起 @TC501，退後兩步，雙手舉起設備，背面鏡頭對準整個棧板，表情輕鬆。人物在畫面左側三分之二。 + 共用設定
```
後期在 12 秒左右，畫面右側會疊入 TC501 螢幕示意。

## R3 同時讀取（12 秒 → `assets/clips/r3.mp4`）
```
側後方越肩鏡頭，人物和棧板在畫面左側三分之二，雙手穩定持 @TC501 對準整個棧板，螢幕背向鏡頭；畫面右側三分之一是虛化的貨架遠景，保持簡潔。鏡頭穩定，輕微推近。 + 共用設定
```

## R5 收貨核對（10 秒 → `assets/clips/r5.mp4`）
```
同一棧板，固定鏡頭。人物低頭看 @TC501 螢幕（螢幕背向鏡頭），然後滿意地點頭，放下設備。人物在畫面左側三分之二，右側保持簡潔。 + 共用設定
```
後期會把畫面左半壓暗，放上收貨單面板。
